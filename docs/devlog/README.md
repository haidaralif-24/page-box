# Devlog

Short notes on what I built, what broke, and what I learned. Add one file per session
or milestone, named like `2026-11-12-project-setup.md`.

Why keep this: it shows the thinking behind the project, which is great material
for college essays and interviews.

## Template

```md
# <date> - <title>

## What I did
-

## What went wrong
-

## What I learned
-

## Next
-
```
