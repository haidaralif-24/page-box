# Devlog

One entry: **[The Speedrun](the-speedrun.md)** — the whole build, told in phases.

Pagebox is a speedrun project (idea → installers in a few intense sessions), so
dated per-session entries would be fake precision. The real timeline lives in
`git log`; each phase in the log cites its commit SHAs.

The log also states up front how much of this was built with AI (**Qwen4-Max**)
and what I actually did. Why keep this: it shows the thinking behind the
project, which is great material for college essays and interviews.

The old per-session files are kept as redirect stubs so existing links don't
break; their original text is preserved in git history.

## Format

Each phase: **What I did / What went wrong / What I learned**, ending with the
commits it covers. One shared **Next** at the bottom of the log.
