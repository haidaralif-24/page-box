# 2026-11-18 - v0.1: paste and preview

## What I did
- Replaced the Tauri starter demo with the real v0.1 app:
  - Rust backend: `cleaning.rs` (fence stripping, HTML extraction, title detection),
    `storage.rs` (UUID page dirs under app-data with `current.html` + `meta.json`),
    commands `add_page`, `list_pages`, `get_page_html`, `delete_page`.
  - React frontend: gallery of page cards, paste dialog with live title detection
    and a "doesn't look like HTML" warning, sandboxed preview, delete with confirm.
- Preview security per SECURITY.md: `<iframe sandbox="allow-scripts" srcdoc>`
  (no `allow-same-origin`), CSP meta injected before render, network off by default.
- Set the app CSP in `tauri.conf.json` (was `null`), renamed everything from
  `tauri-app` to Pagebox, dropped the unused opener plugin/permission.
- Added vitest + 17 unit tests for cleaning and CSP injection; mirrored Rust tests
  in `cleaning.rs`. `pnpm build` (tsc + vite) passes.
- `pnpm dev` now also works in a plain browser with a labeled localStorage mock
  backend, so the UI can be demoed without a desktop build.
- Delete page was pulled forward from v0.2 — it's tiny and makes testing sane.

## What went wrong
- `srcdoc` iframes inherit the parent's CSP. A "strict" app CSP without
  `'unsafe-inline'` would silently break every previewed page's inline scripts.
  The app CSP therefore allows inline scripts/styles; isolation comes from the
  sandbox's opaque origin, and the injected meta CSP locks the page down further.
- A naive `/<head[^>]*>/` injection regex also matches `<header>` — needed
  `/<head(?:\s[^>]*)?>/` so the CSP meta lands in the right place.
- Lowercasing a whole string before searching shifts byte indices for some
  Unicode input; the Rust cleaner searches ASCII-case-insensitively over the
  original bytes instead.

## What I learned
- Sandbox flags and CSP do different jobs: the sandbox isolates the page from
  the app; the CSP isolates it from the network. You need both.
- Mirroring logic in TS (instant UI feedback) and Rust (source of truth on save)
  works well, but the two need paired tests to stay in sync.
